# Project Context: Antlyst.xyz

**Last Updated:** 2026-02-02
**Current Phase:** Live / Maintenance & Scaling

## 1. Project Overview
**Antlyst.xyz** is a **collaborative data analytics SaaS** that empowers teams to visualize, share, and discuss their data instantly. 

The core value proposition is "Zero-Config Dashboards": Users upload a raw CSV, and Antlyst automatically generates interactive, insight-rich dashboards using one of three engines:
1.  **Simple**: Quick, clean statistical overviews.
2.  **ML-Enhanced**: Predictive trends, clusters, and advanced pattern recognition.
3.  **Power BI Style**: A robust, business-intelligence style layout for executives.

Unlike static tools, Antlyst is built for **Teams**. It features organization-based workspaces, real-time chat channels for discussing data, and a seamless invite system.

**Mission:** Democratize high-level data intelligence. Turn any CSV into a boardroom-ready presentation in seconds.

## 2. Technology Stack
An advanced, production-grade Next.js 15 application deployed on Vercel.

-   **Framework:** Next.js 15 (App Router, Server Actions).
-   **Language:** TypeScript (Strict Mode).
-   **Styling:** Tailwind CSS, Shadcn UI (Radix Primitives), Framer Motion (Animations).
-   **Database:** PostgreSQL (Prisma ORM). Managed by Supabase (mostly for Realtime/Connection pooling).
-   **Authentication:** Clerk (User Mgmt) synced with internal Tables via Webhooks.
-   **Storage:** Cloudflare R2 (S3-compatible) for raw CSV storage.
    -   *Key Feature:* Direct Browser-to-R2 uploads using Signed URLs (bypasses Server limits).
-   **Real-time:** Supabase Realtime (Postgres Changes) for Chat & Notifications.
-   **Visualization:** Recharts, Plotly.js.

## 3. Key Features

### Data Pipeline & Analysis
-   **Smart Upload Wizard:** 
    -   Drag-and-drop CSV/Excel.
    -   Client-side parsing preview (Web Workers).
    -   Direct-to-R2 upload (CORS-enabled for Scale).
    -   Mobile-responsive design.
-   **Dashboard Engines:** 
    -   Selectable styles (Simple/ML/PowerBI) trigger different algorithmic pipelines.
    -   Auto-generated charts based on column data types.

### Organization & Team Management
-   **Multi-Tenancy:** Users can belong to multiple Organizations.
-   **Invite System:** 
    -   Shareable `join/[code]` links.
    -   Role-based access (Owner vs Member).
    -   Invite notifications for existing members.
-   **Management:** 
    -   Promote/Demote members.
    -   Delete Organization (Owner only).
    -   Kick members.

### Collaboration & Chat
-   **Real-time Chat:**
    -   Slack-like interface (`ChatWindow.tsx`).
    -   Organization-wide `#general` channels.
    -   Optimistic UI updates for zero-latency feel.
    -   Mobile-responsive (sticky inputs, adaptive height).
-   **Notifications:**
    -   New Member alerts.
    -   Upload completion alerts.

## 4. Architecture Highlights

### SaaS Data Model
-   **Users** (Clerk) <-> **OrgMembership** <-> **Organization**.
-   **Projects** belong to **Organizations**, not just Users.
-   **Files** are stored in R2, metadata in Postgres.

### Performance Optimizations (Fast Routes)
-   **Public Routes:** Landing, Pricing, and Sign-in are statically optimized or cached.
-   **Heavy Computation:** CSV parsing is offloaded to Client Web Workers or async Server Actions.
-   **Bundle Size:** Heavy charting libraries (Plotly) are lazy-loaded.
